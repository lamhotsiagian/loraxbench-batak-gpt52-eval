This repository contains materials for the study:

**Evaluating GPT-5.2 on Batak Toba Language Accuracy and Multi-Metric Analysis with BLEU, METEOR, ROUGE, BERTScore, and COMET**  
**Author:** Lamhot Siagian — University of the Cumberlands  
**DOI:** 10.13140/RG.2.2.10015.83369  
**ResearchGate:** https://www.researchgate.net/publication/399417130_Evaluating_GPT-52_on_Batak_Toba_Language_Accuracy_and_Multi-Metric_Analysis_with_BLEU_METEOR_ROUGE_BERTScore_and_COMET

## Overview

Batak Toba is a low-resource language and LLM outputs can appear fluent while being semantically or culturally incorrect.  
This work evaluates GPT-5.2 outputs on Batak Toba tasks using multiple automatic metrics:

- **BLEU**
- **METEOR**
- **ROUGE**
- **BERTScore**
- **COMET**

Using multiple metrics helps capture both surface overlap and semantic similarity.

## Outputs

Typical outputs include:

* `results/scores.csv` — per-sample metric scores and summary statistics
* `results/error_cases.csv` — qualitative error cases (off-topic, hallucination, cultural mismatch)
